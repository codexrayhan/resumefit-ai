Security

Last updated: June 2026

1. Our Security Approach

ResumeFit AI is designed with a simple, honest security model: process what you send, return the result, keep nothing. There are no user accounts to compromise, no database to breach, and no credentials of any kind stored anywhere in the system.

All computation happens server-side in Python. The ML models — SBERT all-MiniLM-L6-v2, the LinearSVC classifier, and the TF-IDF vectorizers — are loaded from local .pkl files. No external API call is ever made during analysis.

2. File Handling

Uploaded files are held in a temporary buffer for the duration of text extraction only — usually under a second. They are never written to permanent disk storage. Once the text has been extracted, the buffer is discarded.

Flask enforces a hard upload limit of 5 MB per request. Any file exceeding this limit is rejected before processing begins.

File type is validated server-side by checking the file extension. Only .pdf, .docx, and .txt files are accepted. Any other extension is rejected with an error before any content is read.

3. Data Transmission

In a local deployment, your resume file travels only from your browser to localhost. It never leaves your machine. No data is forwarded to any external server, cloud service, or third party at any point during analysis.

If the app is deployed to a remote server, the file upload travels over the network connection between your browser and that server. We recommend running the app over HTTPS in any network-accessible deployment.

4. What We Do Not Collect

We do not collect, store, or process any of the following:

  • Passwords or authentication credentials
  • Payment or financial information
  • Email addresses or phone numbers
  • IP addresses or device fingerprints
  • Browser history or behavioral analytics

There is simply no mechanism in this application to collect any of the above. The attack surface is limited to the resume text and job description you choose to submit.

5. Responsible Disclosure

If you discover a security vulnerability in ResumeFit AI, please report it responsibly. Do not publish details publicly before giving us a chance to address it.

Open a private or public issue on our GitHub repository and describe what you found. We will respond as quickly as we can.

6. Limitations

ResumeFit AI is a university course project, not a hardened production application. It has not undergone a formal security audit or penetration test.

Flask's built-in development server and debug mode must be disabled before any public-facing deployment. Running with debug=True in production exposes an interactive debugger that can execute arbitrary code. We strongly recommend using a production-grade WSGI server (such as Gunicorn) if you deploy this application beyond a local demo.

7. Contact

For security concerns or general questions, please reach out via our GitHub repository.
